# AuctionCraze Design System

- **Palette**: Midnight Stadium Navy (`#060A14` canvas, `#0C1322` surface, `#131D33` card, `#1A2744` elevated), Metallic Championship Gold (`#F5D061` / `#D4AF37`), Electric Stadium Blue (`#38BDF8` / `#2563EB`), Emerald (`#10B981` SOLD), Crimson (`#EF4444` UNSOLD / urgent timer).
- **Typography**: `Barlow Condensed` (display, room codes, bid amounts), `Plus Jakarta Sans` (UI controls & chat), `JetBrains Mono` (`tabular-nums` purses & timers).
- **Identity**: Original stadium broadcast & multiplayer gaming aesthetic; zero Gokul Cup / AuctionOS / third-party proprietary UI assets.
